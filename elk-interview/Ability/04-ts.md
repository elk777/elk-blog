

### 谈谈对TS的理解

TypeScript 是微软开发的 JavaScript 超集，在 JS 的基础上增加了**静态类型系统**。代码需要经过编译（`tsc`）转为 JavaScript 后才能运行。

**核心优势：**
- **类型安全**：在编译阶段捕获类型错误，减少运行时异常
- **更好的开发体验**：IDE 自动补全、接口提示、重构支持
- **代码可读性**：类型即文档，降低协作成本
- **兼容性**：完全兼容 JS，可渐进式引入

**适用场景：**
- 中大型项目、多人协作、长期维护项目
- 组件库/工具库开发（如 Vue 3、Ant Design 全面使用 TS）
- 全栈开发（NestJS、tRPC 等）

**当前行情：** 2024-2025 年前端领域 TS 已成为主流，Vue 3、React 18+ 生态全面拥抱 TS，大多数中大型项目的标配。


### TypeScript的基本语法

```typescript
// 变量声明与类型标注
let name: string = 'elk';
let age: number = 25;
let isActive: boolean = true;

// 函数类型标注
function add(a: number, b: number): number {
  return a + b;
}

// 箭头函数
const greet = (name: string): string => `Hello, ${name}`;

// 类型推断（TS 会自动推断类型，无需手动标注）
let count = 10;          // 推断为 number
let items = [1, 2, 3];   // 推断为 number[]

// 类型别名
type ID = string | number;

// 接口定义
interface User {
  name: string;
  age: number;
}

// 类
class Person implements User {
  constructor(public name: string, public age: number) {}
}
```

**编译与运行：**
```bash
# 编译单个文件
tsc index.ts

# 初始化配置文件
tsc --init

# 带配置编译
tsc -p tsconfig.json
```


### TypeScript的数据类型

#### 基本类型

```typescript
// 基本类型
let str: string = 'hello';
let num: number = 42;
let bool: boolean = true;
let n: null = null;
let u: undefined = undefined;
let sym: symbol = Symbol('id');
let big: bigint = 9007199254740991n;
```

#### 数组与元组

```typescript
// 数组
let arr1: number[] = [1, 2, 3];
let arr2: Array<number> = [1, 2, 3];
let arr3: (string | number)[] = [1, 'two', 3];

// 元组（固定长度、固定类型的数组）
let tuple: [string, number] = ['elk', 25];
// tuple = [25, 'elk']; // 报错：类型不匹配
```

#### 对象类型

```typescript
// 接口定义
interface User {
  name: string;
  age: number;
  email?: string;       // 可选属性
  readonly id: number;  // 只读属性
}

// 类型别名
type User = {
  name: string;
  age: number;
}

// 索引签名
interface StringMap {
  [key: string]: string;
}
```

#### 联合类型与交叉类型

```typescript
// 联合类型（A 或 B）
type ID = string | number;
let id: ID = 'abc';
id = 123;

// 交叉类型（A 且 B，合并多个类型）
type Person = { name: string };
type Employee = { company: string };
type Staff = Person & Employee;
// Staff 必须同时包含 name 和 company
```

#### 字面量类型

```typescript
type Direction = 'up' | 'down' | 'left' | 'right';
type Status = 0 | 1 | 2;
type Exact = { type: 'user' } | { type: 'admin' };
```

#### typeof 类型查询

```typescript
const config = {
  host: 'localhost',
  port: 3306,
  debug: true
};

type Config = typeof config;
// 等价于 { host: string; port: number; debug: boolean }
```

#### keyof 操作符

```typescript
interface User {
  name: string;
  age: number;
}

type UserKeys = keyof User;  // 'name' | 'age'

// 实际应用：类型安全的对象属性访问
function getProperty<T, K extends keyof T>(obj: T, key: K): T[K] {
  return obj[key];
}
```

#### any vs unknown vs never

```typescript
// any：关闭类型检查（尽量避免使用）
let a: any = 'hello';
a.toFixed();  // 不报错，运行时可能出错

// unknown：类型安全的 any（推荐替代 any）
let b: unknown = 'hello';
// b.toFixed();  // 报错：必须先进行类型检查
if (typeof b === 'string') {
  b.toFixed();  // 通过类型守卫后可用
}

// never：永不存在的值的类型
function throwError(msg: string): never {
  throw new Error(msg);
}

// 穷举检查
type Shape = 'circle' | 'square';
function getArea(shape: Shape) {
  switch (shape) {
    case 'circle': return Math.PI;
    case 'square': return 1;
    default: const _exhaustive: never = shape; // 确保所有分支都被处理
  }
}
```


### TypeScript的函数

```typescript
// 函数类型
type AddFn = (a: number, b: number) => number;

// 接口定义函数
interface MathFn {
  (a: number, b: number): number;
}

// 可选参数和默认参数
function createUser(name: string, age: number = 18, email?: string) {}

// 剩余参数
function sum(...nums: number[]): number {
  return nums.reduce((total, n) => total + n, 0);
}

// 函数重载
function format(value: string): string;
function format(value: number): string;
function format(value: string | number): string {
  if (typeof value === 'string') return value.trim();
  return value.toFixed(2);
}

// this 类型绑定
interface Card {
  suit: string;
  card: number;
}
interface Deck {
  suits: string[];
  cards: number[];
  pickCard(this: Deck): () => Card;
}

// 泛型函数
function identity<T>(arg: T): T {
  return arg;
}
```

**常见面试追问：函数重载和联合类型的区别？**
函数重载提供更精确的类型签名，IDE 能根据传参类型推断返回类型。联合类型只能返回所有可能类型的联合。


### TypeScript的类

```typescript
class Animal {
  // 访问修饰符：public（默认）、private、protected
  public name: string;
  private _id: number;
  protected species: string;

  // 静态属性
  static count = 0;

  // 只读属性
  readonly birthDate: Date;

  constructor(name: string, species: string) {
    this.name = name;
    this._id = ++Animal.count;
    this.species = species;
    this.birthDate = new Date();
  }

  // getter/setter
  get id(): number {
    return this._id;
  }

  // 方法
  speak(): string {
    return `${this.name} makes a sound`;
  }

  // 静态方法
  static getCount(): number {
    return Animal.count;
  }
}

// 继承
class Dog extends Animal {
  constructor(name: string) {
    super(name, 'dog'); // 必须调用 super
  }

  // 方法重写
  speak(): string {
    return `${this.name} barks`;
  }
}

// 抽象类（不能直接实例化）
abstract class Shape {
  abstract area(): number; // 抽象方法，子类必须实现
  describe(): string {
    return `Area: ${this.area()}`;
  }
}

class Circle extends Shape {
  constructor(private radius: number) { super(); }
  area(): number {
    return Math.PI * this.radius ** 2;
  }
}

// 实现接口
interface Printable {
  print(): void;
}

class Document implements Printable {
  print() { console.log('printing'); }
}

// 参数属性简写
class Point {
  constructor(public x: number, public y: number) {}
  // 等价于声明 public x: number; public y: number; + constructor 中赋值
}
```

**常见面试追问：private vs protected 的区别？**
`private` 只能在当前类内部访问，子类也无法访问。`protected` 子类可以访问。`public` 任何地方都能访问。


### TypeScript的接口

```typescript
// 基本接口
interface User {
  name: string;
  age: number;
  email?: string;       // 可选
  readonly id: string;  // 只读
}

// 接口继承
interface Employee extends User {
  department: string;
  salary: number;
}

// 多重继承
interface Admin extends User, Employee {
  permissions: string[];
}

// 函数接口
interface SearchFn {
  (source: string, keyword: string): boolean;
}

// 索引接口
interface StringArray {
  [index: number]: string;
}

// 泛型接口
interface ApiResponse<T> {
  code: number;
  message: string;
  data: T;
}

// 类实现接口
class UserService implements User {
  constructor(public name: string, public age: number, public id: string) {}
}
```

#### interface vs type 区别

| 特性 | interface | type |
|------|-----------|------|
| 定义对象结构 | 支持 | 支持 |
| 扩展（继承） | `extends` | `&` 交叉类型 |
| 合并声明 | 支持（同名自动合并） | 不支持 |
| 联合/交叉类型 | 不支持 | 支持 |
| 元组/映射类型 | 不支持 | 支持 |
| 基本类型别名 | 不支持 | 支持 |
| 实现（implements） | 支持 | 支持（但建议用 interface） |

```typescript
// interface 声明合并（独特能力）
interface Config { host: string; }
interface Config { port: number; }
// 自动合并为 { host: string; port: number }

// type 的独特能力
type ID = string | number;          // 联合类型
type Pair = [string, number];       // 元组
type Keys = keyof User;             // 操作符
```

**最佳实践**：定义对象结构优先用 `interface`，需要联合类型、元组、高级类型操作时用 `type`。


### TypeScript的枚举

```typescript
// 数字枚举（默认从 0 开始递增）
enum Direction {
  Up,       // 0
  Down,     // 1
  Left,     // 2
  Right     // 3
}

// 自定义起始值
enum Status {
  Pending = 1,
  Active,   // 2
  Disabled  // 3
}

// 字符串枚举
enum Color {
  Red = 'red',
  Green = 'green',
  Blue = 'blue'
}

// 使用
const dir = Direction.Up;
const name = Direction[0]; // 'Up'（反向映射，仅数字枚举支持）

// 常量枚编译时会被内联，不生成额外代码
const enum HttpMethod {
  GET = 'GET',
  POST = 'POST'
}
```

#### 枚举 vs 联合类型

```typescript
// 枚举的问题：编译后生成冗余代码、与 JS 互操作不够自然
// 现代推荐：用联合类型 + as const 替代
const Direction = {
  Up: 'up',
  Down: 'down',
  Left: 'left',
  Right: 'right'
} as const;

type Direction = typeof Direction[keyof typeof Direction];
// 'up' | 'down' | 'left' | 'right'
```

**当前行情**：越来越多的项目倾向使用联合类型替代枚举，因为编译产物更小、与 JS 生态更融合。但在需要明确常量集合、有反向映射需求时，枚举仍有价值。


### TypeScript的类型断言

```typescript
// 类型断言（告诉编译器"我比你更清楚类型"）
const input = document.getElementById('input') as HTMLInputElement;
const value = (<HTMLInputElement>input).value;

// 非空断言（!）：确信值不为 null/undefined
const el = document.getElementById('app')!;
el.style.display = 'none';

// const 断言（as const）：将值推断为最窄的字面量类型
let str = 'hello' as const;   // 类型为 'hello'（非 string）
let arr = [1, 2, 3] as const; // 类型为 readonly [1, 2, 3]
let obj = { x: 1 } as const;  // 类型为 { readonly x: 1 }

// satisfies 操作符（TS 4.9+）：检查类型兼容但保留更精确的推断
type Color = 'red' | 'green' | 'blue';
const palette = {
  red: [255, 0, 0],
  green: '#00ff00',
  blue: [0, 0, 255]
} satisfies Record<Color, string | number[]>;
// palette.red 的类型是 number[]（而非 string | number[]）
// palette.green 的类型是 string
```

**常见面试追问：类型断言会报错吗？什么时候会？**
类型断言不进行运行时转换，只是编译时提示。如果两个类型完全不兼容（如 `string as number`），TS 会报错。双重断言 `as unknown as TargetType` 可以绕过，但应避免使用。


### TypeScript的装饰器

装饰器是一种特殊声明，可以附加到类、方法、属性、参数上，用于修改或扩展其行为。需要开启 `experimentalDecorators`。

```typescript
// 类装饰器
function Sealed(constructor: Function) {
  Object.seal(constructor);
  Object.seal(constructor.prototype);
}

@Sealed
class BugReport {
  title: string;
  constructor(t: string) { this.title = t; }
}

// 方法装饰器
function log(target: any, key: string, descriptor: PropertyDescriptor) {
  const original = descriptor.value;
  descriptor.value = function (...args: any[]) {
    console.log(`Calling ${key} with`, args);
    return original.apply(this, args);
  };
  return descriptor;
}

class Calculator {
  @log
  add(a: number, b: number): number {
    return a + b;
  }
}

// 装饰器工厂（返回装饰器的函数）
function color(value: string) {
  return function (constructor: Function) {
    // 使用 value 参数
    console.log(`Color: ${value}`);
  };
}

@color('red')
class Car {}

// 属性装饰器
function readonly(target: any, key: string) {
  Object.defineProperty(target, key, { writable: false });
}

// 参数装饰器
function required(target: any, key: string, index: number) {
  // 记录需要验证的参数索引
}

// TC39 Stage 3 装饰器（ES2023+，新一代标准）
// 与 experimentalDecorators 不同，新装饰器语法更统一
// class MyClass {
//   @decorator
//   method() {}
// }
```

**当前行情**：装饰器在 NestJS 中被大量使用（`@Controller()`、`@Injectable()`、`@Get()`），理解装饰器原理对于 NestJS 开发非常重要。Angular 也广泛使用装饰器。


### TypeScript的泛型

泛型是指在定义函数、接口或类时不预先指定类型，而在使用时再指定类型。

#### 基本用法

```typescript
// 泛型函数
function identity<T>(arg: T): T {
  return arg;
}

identity<string>('hello');  // 显式指定类型
identity(42);               // 类型推断

// 多个泛型参数
function swap<T, U>(a: T, b: U): [U, T] {
  return [b, a];
}
```

#### 泛型约束

```typescript
// 约束泛型必须具有特定属性
interface HasLength {
  length: number;
}

function logLength<T extends HasLength>(arg: T): T {
  console.log(arg.length);
  return arg;
}

logLength('hello');     // OK，string 有 length
logLength([1, 2, 3]);   // OK，数组有 length
// logLength(42);       // 报错：number 没有 length

// keyof 约束
function getProperty<T, K extends keyof T>(obj: T, key: K): T[K] {
  return obj[key];
}
```

#### 泛型接口与泛型类

```typescript
// 泛型接口
interface ApiResponse<T> {
  code: number;
  data: T;
  message: string;
}

const userRes: ApiResponse<User> = { code: 200, data: { name: 'elk' }, message: 'ok' };

// 泛型类
class Stack<T> {
  private items: T[] = [];
  push(item: T): void { this.items.push(item); }
  pop(): T | undefined { return this.items.pop(); }
  peek(): T | undefined { return this.items[this.items.length - 1]; }
}

const numStack = new Stack<number>();
```

#### 条件类型

```typescript
// 条件类型：T extends U ? X : Y
type IsString<T> = T extends string ? 'yes' : 'no';
type A = IsString<string>;  // 'yes'
type B = IsString<number>;  // 'no'

// 分布式条件类型（联合类型展开）
type ToArray<T> = T extends any ? T[] : never;
type Result = ToArray<string | number>; // string[] | number[]
```

#### infer 关键字

```typescript
// infer 在条件类型中推断类型
type ReturnType<T> = T extends (...args: any[]) => infer R ? R : never;
type FnReturn = ReturnType<() => string>; // string

// 提取函数参数类型
type Parameters<T> = T extends (...args: infer P) => any ? P : never;
type FnParams = Parameters<(a: string, b: number) => void>; // [string, number]

// 提取数组元素类型
type Element<T> = T extends (infer E)[] ? E : never;
type ArrEl = Element<string[]>; // string

// 提取 Promise 内部类型
type UnwrapPromise<T> = T extends Promise<infer U> ? U : T;
type Res = UnwrapPromise<Promise<User>>; // User
```

#### 内置工具类型

| 工具类型 | 作用 | 示例 |
|---------|------|------|
| `Partial<T>` | 所有属性变为可选 | `Partial<User>` |
| `Required<T>` | 所有属性变为必填 | `Required<Partial<User>>` |
| `Readonly<T>` | 所有属性变为只读 | `Readonly<User>` |
| `Pick<T, K>` | 选取部分属性 | `Pick<User, 'name' \| 'age'>` |
| `Omit<T, K>` | 排除部分属性 | `Omit<User, 'password'>` |
| `Record<K, V>` | 构造键值对类型 | `Record<string, number>` |
| `Exclude<T, U>` | 从联合类型中排除 | `Exclude<'a' \| 'b', 'a'>` → `'b'` |
| `Extract<T, U>` | 从联合类型中提取 | `Extract<'a' \| 'b', 'a'>` → `'a'` |
| `NonNullable<T>` | 排除 null 和 undefined | `NonNullable<string \| null>` → `string` |
| `ReturnType<T>` | 获取函数返回类型 | `ReturnType<typeof fn>` |
| `Parameters<T>` | 获取函数参数类型 | `Parameters<typeof fn>` |

```typescript
// 实际应用：表单更新场景
interface UserForm {
  name: string;
  email: string;
  age: number;
  avatar: string;
}

// 更新时所有字段可选
function updateUser(id: string, data: Partial<UserForm>) {}

// 创建时所有字段必填
function createUser(data: UserForm) {}

// 只暴露安全字段
type PublicUser = Omit<UserForm, 'email'>;
```

#### 映射类型

```typescript
// 手动实现 Partial
type MyPartial<T> = {
  [K in keyof T]?: T[K];
};

// 手动实现 Readonly
type MyReadonly<T> = {
  readonly [K in keyof T]: T[K];
};

// 键名重映射（TS 4.1+）
type Getters<T> = {
  [K in keyof T as `get${Capitalize<string & K>}`]: () => T[K];
};
type UserGetters = Getters<User>;
// { getName: () => string; getAge: () => number; }
```
