


### JavaScript数据类型

JavaScript 中的数据类型分为两大类：**基本类型（Primitive）** 和 **引用类型（Reference）**。

#### 基本类型（7种）

| 类型 | 示例 | 特点 |
|------|------|------|
| `string` | `'hello'` | 不可变，按值传递 |
| `number` | `42`、`3.14`、`NaN`、`Infinity` | 64位浮点数，无独立整数类型 |
| `boolean` | `true`、`false` | |
| `null` | `null` | 表示"空值"，主动赋空 |
| `undefined` | `undefined` | 表示"未定义"，变量声明未赋值 |
| `symbol` | `Symbol('id')` | 唯一标识符，不可枚举 |
| `bigint` | `9007199254740991n` | 任意精度整数，ES2020 引入 |

基本类型存储在**栈内存**中，按值访问和传递。

#### 引用类型

| 类型 | 示例 |
|------|------|
| `Object` | `{}`、`[]`、`function(){}`、`new Date()`、`/regex/` |
| `Array` | `[1, 2, 3]` |
| `Function` | `function() {}` |
| `Date`、`RegExp`、`Map`、`Set` 等 | 特殊内置对象 |

引用类型存储在**堆内存**中，变量保存的是指向堆内存的引用地址。

```js
// 基本类型：值传递
let a = 10;
let b = a;
b = 20;
console.log(a); // 10，互不影响

// 引用类型：引用传递
let obj1 = { name: 'elk' };
let obj2 = obj1;
obj2.name = 'cat';
console.log(obj1.name); // 'cat'，指向同一对象
```


### JavaScript类型判断方法

#### typeof

`typeof` 用于判断基本类型，但无法区分 `null` 和引用类型的具体类型。

```js
typeof 'hello'      // 'string'
typeof 42            // 'number'
typeof true          // 'boolean'
typeof undefined     // 'undefined'
typeof Symbol()      // 'symbol'
typeof 10n           // 'bigint'
typeof {}            // 'object'
typeof []            // 'object'   （数组也是对象）
typeof null          // 'object'   （历史遗留 Bug）
typeof function(){}  // 'function'
```

#### instanceof

`instanceof` 用于判断引用类型的原型链，不能用于基本类型。

```js
[] instanceof Array       // true
[] instanceof Object      // true（原型链上能找到）
new Date() instanceof Date // true
```

#### Object.prototype.toString.call

最精确的类型判断方式，返回 `[object Type]` 格式的字符串。

```js
Object.prototype.toString.call('hello')   // '[object String]'
Object.prototype.toString.call(42)        // '[object Number]'
Object.prototype.toString.call(null)      // '[object Null]'
Object.prototype.toString.call(undefined) // '[object Undefined]'
Object.prototype.toString.call([])        // '[object Array]'
Object.prototype.toString.call({})        // '[object Object]'
Object.prototype.toString.call(new Date())// '[object Date]'
Object.prototype.toString.call(/abc/)     // '[object RegExp]'
```

#### Array.isArray

专门判断数组，避免 `instanceof` 在跨 iframe 场景下的问题。

```js
Array.isArray([1, 2, 3])  // true
Array.isArray('hello')     // false
```

#### 各方法对比

| 方法 | 基本类型 | 引用类型 | null | 跨 iframe |
|------|---------|---------|------|-----------|
| `typeof` | 能区分 | 仅区分 function | 错误返回 object | 可用 |
| `instanceof` | 不能 | 能区分 | false | 不可靠 |
| `Object.prototype.toString` | 能区分 | 能区分 | 能区分 | 可用 |


### 本地存储

JavaScript 提供了多种客户端存储方案：

| 方式 | 容量 | 生命周期 | 作用域 | 适用场景 |
|------|------|---------|--------|---------|
| `localStorage` | 约 5-10MB | 永久，手动清除 | 同源（协议+域名+端口） | 长期配置、用户偏好 |
| `sessionStorage` | 约 5-10MB | 会话结束（关闭标签页） | 同源 + 同标签页 | 临时表单数据、页面状态 |
| `cookie` | 约 4KB | 可设过期时间 | 可设 domain/path | 身份认证、自动登录 |
| `IndexedDB` | 无上限（依磁盘） | 永久 | 同源 | 大量结构化数据、离线应用 |

```js
// localStorage
localStorage.setItem('theme', 'dark');
localStorage.getItem('theme');    // 'dark'
localStorage.removeItem('theme');
localStorage.clear();

// sessionStorage
sessionStorage.setItem('step', '2');

// cookie
document.cookie = 'token=abc123; max-age=3600; path=/; secure; samesite=strict';

// IndexedDB（简略）
const request = indexedDB.open('myDB', 1);
request.onupgradeneeded = (e) => {
  const db = e.target.result;
  db.createObjectStore('users', { keyPath: 'id' });
};
```

#### localStorage vs sessionStorage vs Cookie 对比

- **存储容量**：cookie 最小（4KB），localStorage/sessionStorage 约 5MB，IndexedDB 理论无上限
- **自动携带**：cookie 会在每次 HTTP 请求中自动携带（增加网络开销），localStorage/sessionStorage 不会
- **操作方式**：cookie 操作较繁琐（需手动解析），localStorage/sessionStorage 提供简洁的 API
- **安全建议**：敏感信息不要存 localStorage（易受 XSS 攻击），cookie 可设 `HttpOnly` 阻止 JS 读取


### 防抖与节流

#### 防抖（Debounce）

防抖的核心思想：**在事件触发后等待一段时间，如果期间再次触发则重新计时**。只有最后一次触发会被执行。

适用场景：搜索框输入联想、窗口 resize 完成后计算布局、表单验证。

```js
function debounce(fn, delay = 300) {
  let timer = null;
  return function (...args) {
    clearTimeout(timer);
    timer = setTimeout(() => {
      fn.apply(this, args);
    }, delay);
  };
}

// 使用
const search = debounce((keyword) => {
  console.log('搜索:', keyword);
}, 500);

input.addEventListener('input', (e) => search(e.target.value));
```

#### 节流（Throttle）

节流的核心思想：**在一段时间内只执行一次，无论事件触发多少次**。

适用场景：滚动事件监听、鼠标移动跟踪、按钮防重复点击。

```js
// 时间戳方式（首次立即执行）
function throttle(fn, interval = 300) {
  let lastTime = 0;
  return function (...args) {
    const now = Date.now();
    if (now - lastTime >= interval) {
      lastTime = now;
      fn.apply(this, args);
    }
  };
}

// 定时器方式（首次延迟执行）
function throttleTimer(fn, interval = 300) {
  let timer = null;
  return function (...args) {
    if (timer) return;
    timer = setTimeout(() => {
      fn.apply(this, args);
      timer = null;
    }, interval);
  };
}

// 使用
window.addEventListener('scroll', throttle(() => {
  console.log('滚动位置:', window.scrollY);
}, 200));
```

#### 防抖与节流的区别

| 特性 | 防抖 | 节流 |
|------|------|------|
| 执行时机 | 事件停止后延迟执行 | 固定时间间隔执行 |
| 执行次数 | 只执行最后一次 | 固定频率执行 |
| 典型场景 | 输入搜索、resize | 滚动监听、拖拽 |


### ES6常用新特性

#### 变量声明：let 与 const

`let` 和 `const` 解决了 `var` 的诸多问题：

| 特性 | `var` | `let` / `const` |
|------|-------|-----------------|
| 作用域 | 函数作用域 | 块级作用域 `{}` |
| 变量提升 | 有（值为 undefined） | 有（暂时性死区 TDZ） |
| 重复声明 | 允许 | 不允许 |
| 全局对象属性 | 是（`window.var`） | 否 |

```js
// var 的问题：循环中闭包共享变量
for (var i = 0; i < 3; i++) {
  setTimeout(() => console.log(i), 100);
}
// 输出: 3, 3, 3

// let 解决：每次循环创建新的块级作用域
for (let i = 0; i < 3; i++) {
  setTimeout(() => console.log(i), 100);
}
// 输出: 0, 1, 2

// const：声明常量，不可重新赋值（引用类型内部可修改）
const obj = { name: 'elk' };
obj.name = 'cat';       // 可以修改内部属性
obj = {};               // 报错：不可重新赋值
```

**最佳实践**：默认使用 `const`，需要重新赋值时才用 `let`，避免使用 `var`。

// 数组解构

### 箭头函数与普通函数的区别

| 特性 | 普通函数 | 箭头函数 |
|------|---------|---------|
| `this` 指向 | 调用时决定（动态绑定） | 定义时继承外层 `this`（词法绑定） |
| `arguments` 对象 | 有 | 没有（可用 `...args` 替代） |
| `new` 调用 | 可以 | 不可以（没有 `[[Construct]]`） |
| `prototype` | 有 | 没有 |
| 用作对象方法 | `this` 指向调用者 | `this` 指向外层（非对象本身） |

```js
const obj = {
  name: 'elk',
  // 普通函数：this 指向 obj
  greet() {
    console.log(this.name); // 'elk'
  },
  // 箭头函数：this 指向外层（非 obj）
  greetArrow: () => {
    console.log(this.name); // undefined
  }
};

// 箭头函数不能用作构造函数
const Cat = () => {};
// new Cat(); // TypeError: Cat is not a constructor

// 箭头函数没有 arguments
const fn = () => {
  // arguments; // ReferenceError
};
const fn2 = (...args) => {
  console.log(args); // 可用剩余参数替代
};

// 箭头函数不能用作 Generator 函数
// const gen = *() => {}; // SyntaxError
```

**选用建议**：
- 回调函数、需要外层 `this` 时：用箭头函数
- 对象方法、构造函数、需要 `arguments` 时：用普通函数


### 闭包

#### 理解

闭包是指**一个函数能够访问其定义时所在作用域的变量，即使该函数在其作用域之外被调用**。

形成闭包的两个条件：
1. 存在函数嵌套
2. 内部函数引用了外部函数的变量

```js
function outer() {
  let count = 0;
  return function inner() {
    count++;
    console.log(count);
  };
}

const counter = outer();
counter(); // 1
counter(); // 2
// outer 执行完毕后，count 仍被 inner 引用，不会被垃圾回收
```

#### 使用场景

**1. 数据私有化（模块模式）**

```js
function createCounter() {
  let count = 0;
  return {
    increment: () => ++count,
    decrement: () => --count,
    getCount: () => count
  };
}

const counter = createCounter();
counter.increment(); // 1
counter.count;       // undefined — count 不可直接访问
```

**2. 函数柯里化**

```js
function multiply(a) {
  return function(b) {
    return a * b;
  };
}

const double = multiply(2);
double(5); // 10
```

**3. 缓存/记忆化**

```js
function memoize(fn) {
  const cache = {};
  return function(...args) {
    const key = JSON.stringify(args);
    if (cache[key] !== undefined) return cache[key];
    return cache[key] = fn.apply(this, args);
  };
}
```

#### 闭包的注意事项

- 闭包会保持对外部变量的引用，可能导致**内存泄漏**
- 在循环中使用闭包时注意变量作用域（`var` vs `let`）
- 不再需要时将闭包引用置为 `null`，便于垃圾回收

```js
// 内存泄漏示例
function leak() {
  const largeData = new Array(1000000).fill('x');
  return function() {
    console.log('do something');
    // largeData 不会被回收
  };
}

// 优化：不需要时释放引用
let handler = leak();
// 使用完毕
handler = null;
```


### 作用域与作用域链

#### 作用域

作用域决定了变量和函数的**可访问范围**。JavaScript 采用**词法作用域**（静态作用域），即作用域在代码编写阶段就已确定，而非运行时决定。

JavaScript 中的作用域类型：

- **全局作用域**：代码最外层，任何地方都能访问
- **函数作用域**：`function` 内部声明的变量，仅函数内可访问
- **块级作用域**：`{}` 内用 `let` / `const` 声明的变量

```js
const globalVar = 'global';

function outer() {
  const outerVar = 'outer';

  function inner() {
    const innerVar = 'inner';
    console.log(globalVar); // 可访问
    console.log(outerVar);  // 可访问
    console.log(innerVar);  // 可访问
  }

  inner();
  // console.log(innerVar); // 报错：无法访问
}

// console.log(outerVar); // 报错：无法访问
```

#### 作用域链

当访问一个变量时，JS 引擎会**从当前作用域开始，逐级向上查找**，直到全局作用域。这条查找路径就是作用域链。

```js
const a = 1;

function fn1() {
  const b = 2;
  function fn2() {
    const c = 3;
    console.log(a + b + c); // 查找顺序: fn2 -> fn1 -> global
  }
  fn2();
}
fn1();
```

作用域链的本质：每个执行上下文都有一个指向外部词法环境的引用，形成链式结构。变量查找就是沿着这个链逐级向上搜索。


### 原型与原型链

#### 原型（Prototype）

每个函数都有一个 `prototype` 属性，指向一个对象，该对象包含可以被该函数的所有实例共享的属性和方法。

每个对象（除 `null`）都有一个 `__proto__`（即 `[[Prototype]]`）属性，指向创建该对象的构造函数的 `prototype`。

```js
function Person(name) {
  this.name = name;
}

Person.prototype.sayHello = function() {
  console.log(`Hello, I'm ${this.name}`);
};

const p1 = new Person('elk');
const p2 = new Person('cat');

p1.sayHello(); // Hello, I'm elk
p2.sayHello(); // Hello, I'm cat

// sayHello 是共享的，而非每个实例各一份
p1.sayHello === p2.sayHello; // true
```

#### 关键关系

```js
// 构造函数的 prototype 是实例的 __proto__
p1.__proto__ === Person.prototype;        // true

// prototype 对象有一个 constructor 指回构造函数
Person.prototype.constructor === Person;  // true

// Function 的 __proto__ 指向 Function.prototype
Person.__proto__ === Function.prototype;  // true

// Object.prototype 是原型链的终点
Person.prototype.__proto__ === Object.prototype; // true
Object.prototype.__proto__ === null;             // true
```

#### 原型链

当访问一个对象的属性时，如果对象自身没有该属性，就沿着 `__proto__` 向上查找，直到找到该属性或到达 `null`。这条链路就是**原型链**。

```js
p1.toString();
// 查找顺序: p1 自身 -> Person.prototype -> Object.prototype (找到 toString) -> null
```

#### instanceof 原理

`A instanceof B` 的判断逻辑：沿着 A 的原型链查找，看是否能找到 B 的 `prototype`。

```js
p1 instanceof Person; // true
p1 instanceof Object; // true
p1 instanceof Array;  // false
```


### 继承方式

#### 1. 原型链继承

```js
function Animal(species) {
  this.species = species;
}
Animal.prototype.eat = function() {
  console.log('eating');
};

function Dog(name) {
  this.name = name;
}
Dog.prototype = new Animal('dog'); // 原型指向父类实例
Dog.prototype.constructor = Dog;

const d = new Dog('旺财');
d.eat(); // eating
```

**缺点**：所有实例共享父类的引用属性，无法向父类传参。

#### 2. 借用构造函数继承

```js
function Animal(species) {
  this.species = species;
}

function Dog(name, species) {
  Animal.call(this, species); // 借用父类构造函数
  this.name = name;
}
```

**缺点**：无法继承父类原型上的方法，每个实例都有一份方法副本。

#### 3. 组合继承（经典继承）

```js
function Animal(species) {
  this.species = species;
}
Animal.prototype.eat = function() {
  console.log('eating');
};

function Dog(name, species) {
  Animal.call(this, species); // 第二次调用父类构造函数
  this.name = name;
}
Dog.prototype = new Animal(); // 第一次调用父类构造函数
Dog.prototype.constructor = Dog;
```

**缺点**：父类构造函数被调用两次。

#### 4. 寄生组合继承（推荐）

```js
function Animal(species) {
  this.species = species;
}
Animal.prototype.eat = function() {
  console.log('eating');
};

function Dog(name, species) {
  Animal.call(this, species);
  this.name = name;
}
// 用 Object.create 创建中间对象，避免二次调用父类构造函数
Dog.prototype = Object.create(Animal.prototype);
Dog.prototype.constructor = Dog;
```

这是 ES5 中最理想的继承方式。

#### 5. ES6 class 继承（现代写法）

```js
class Animal {
  constructor(species) {
    this.species = species;
  }
  eat() {
    console.log('eating');
  }
}

class Dog extends Animal {
  constructor(name, species) {
    super(species); // 必须先调用 super
    this.name = name;
  }
}

const d = new Dog('旺财', 'dog');
d.eat(); // eating
```

`class` + `extends` 本质上是寄生组合继承的语法糖。


### 事件循环机制（Event Loop）

#### 理解

JavaScript 是单线程语言，但通过**事件循环机制**实现了异步操作。事件循环的核心组件：

- **调用栈（Call Stack）**：执行同步代码，后进先出（LIFO）
- **任务队列（Task Queue / Macro Task Queue）**：存放宏任务回调
- **微任务队列（Micro Task Queue）**：存放微任务回调
- **事件循环（Event Loop）**：不断检查调用栈是否为空，为空时先清空微任务队列，再取一个宏任务执行

#### 执行顺序

每次事件循环的执行流程：

1. 执行一个**宏任务**（首次是整个脚本 `script`）
2. 清空**微任务队列**（所有微任务）
3. 如有必要执行渲染
4. 回到第 1 步

```js
console.log('1 - script start');     // 同步

setTimeout(() => {
  console.log('2 - setTimeout');     // 宏任务
}, 0);

Promise.resolve().then(() => {
  console.log('3 - promise then 1'); // 微任务
}).then(() => {
  console.log('4 - promise then 2'); // 微任务（上一个微任务产生的）
});

console.log('5 - script end');        // 同步

// 输出顺序：1 -> 5 -> 3 -> 4 -> 2
```

#### 宏任务与微任务

| 宏任务（Macro Task） | 微任务（Micro Task） |
|---------------------|---------------------|
| `setTimeout` / `setInterval` | `Promise.then` / `.catch` / `.finally` |
| `setImmediate`（Node.js） | `queueMicrotask()` |
| `requestAnimationFrame` | `MutationObserver` |
| I/O 操作 | `process.nextTick`（Node.js，优先级最高） |
| UI 渲染事件 | `async/await`（await 之后的代码） |

```js
async function asyncFn() {
  console.log('A');
  await Promise.resolve();   // await 后面的代码被包装成微任务
  console.log('B');          // 微任务
}
asyncFn();
console.log('C');

// 输出：A -> C -> B
```


### Promise

#### 理解

Promise 是异步编程的一种解决方案，表示一个异步操作的最终完成（或失败）及其结果值。Promise 有三种状态：

- **pending（进行中）**：初始状态
- **fulfilled（已完成）**：操作成功
- **rejected（已失败）**：操作失败

状态一旦改变，就不会再变。

```js
const promise = new Promise((resolve, reject) => {
  // 异步操作
  const success = true;
  if (success) {
    resolve('成功的结果');
  } else {
    reject('失败的原因');
  }
});

promise
  .then(result => console.log(result))
  .catch(error => console.error(error))
  .finally(() => console.log('无论成功失败都执行'));
```

#### 常用 API

```js
// Promise.all — 全部成功才成功，任一失败即失败
const results = await Promise.all([fetch1, fetch2, fetch3]);

// Promise.allSettled — 等待所有完成（无论成功失败）
const results = await Promise.allSettled([p1, p2, p3]);
// [{status:'fulfilled', value:...}, {status:'rejected', reason:...}]

// Promise.race — 取最先完成的结果（成功或失败）
const fastest = await Promise.race([timeout(5000), fetchData()]);

// Promise.any — 取最先成功的，全部失败才 reject
const first = await Promise.any([p1, p2, p3]);

// Promise.resolve / Promise.reject
Promise.resolve(42).then(v => console.log(v));
```

#### 手写简易 Promise

```js
class MyPromise {
  constructor(executor) {
    this.state = 'pending';
    this.value = undefined;
    this.callbacks = [];

    const resolve = (value) => {
      if (this.state !== 'pending') return;
      this.state = 'fulfilled';
      this.value = value;
      this.callbacks.forEach(cb => cb.onFulfilled(value));
    };

    const reject = (reason) => {
      if (this.state !== 'pending') return;
      this.state = 'rejected';
      this.value = reason;
      this.callbacks.forEach(cb => cb.onRejected(reason));
    };

    try {
      executor(resolve, reject);
    } catch (err) {
      reject(err);
    }
  }

  then(onFulfilled, onRejected) {
    return new MyPromise((resolve, reject) => {
      const handle = () => {
        try {
          const result = this.state === 'fulfilled'
            ? (onFulfilled ? onFulfilled(this.value) : this.value)
            : (onRejected ? onRejected(this.value) : (() => { throw this.value; })());
          resolve(result);
        } catch (err) {
          reject(err);
        }
      };

      if (this.state !== 'pending') {
        handle();
      } else {
        this.callbacks.push({ onFulfilled: handle, onRejected: handle });
      }
    });
  }
}
```


### async/await

#### 理解

`async/await` 是基于 Promise 的语法糖，使异步代码看起来像同步代码，更易读写。

- `async` 函数始终返回一个 Promise
- `await` 会暂停 `async` 函数的执行，等待右侧的 Promise 完成
- `await` 后面的代码会被包装成**微任务**

```js
async function fetchData() {
  try {
    const user = await fetchUser();    // 等待完成
    const posts = await fetchPosts(user.id);
    return posts;
  } catch (error) {
    console.error('请求失败:', error);
    throw error;
  }
}
```

#### 常见用法

```js
// 串行执行
async function serial() {
  const a = await taskA();  // 等 taskA 完成
  const b = await taskB();  // 再执行 taskB
  return [a, b];
}

// 并行执行（推荐）
async function parallel() {
  const [a, b] = await Promise.all([taskA(), taskB()]);
  return [a, b];
}

// 并行 + 错误处理
async function parallelWithCatch() {
  const results = await Promise.allSettled([taskA(), taskB()]);
  results.forEach(r => {
    if (r.status === 'fulfilled') console.log(r.value);
    else console.error(r.reason);
  });
}

// for...of 中使用 await（顺序处理数组）
async function processAll(items) {
  for (const item of items) {
    await processItem(item); // 串行
  }
}

// 并行处理数组
async function processAllParallel(items) {
  await Promise.all(items.map(item => processItem(item))); // 并行
}
```

#### 注意事项

1. **不要在非 async 函数中使用 await**
2. **避免不必要的串行 await**：没有依赖关系的请求应该用 `Promise.all` 并行
3. **for 循环中的 await 是串行的**，需要并行时用 `map` + `Promise.all`
4. **顶层 await**（ES2022）：在 ES Module 中可以直接使用 `await`，无需 async 函数包裹

```js
// 错误：不必要的串行（user 和 posts 无依赖关系）
const user = await fetchUser();
const posts = await fetchPosts(); // 被迫等待 fetchUser 完成

// 正确：并行请求
const [user, posts] = await Promise.all([fetchUser(), fetchPosts()]);
```
